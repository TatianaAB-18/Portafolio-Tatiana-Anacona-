# Portafolio de Michelle Tatiana Anacona 🚀

¡Hola! Soy **Michelle Tatiana Anacona**, estudiante de Ingeniería (5º Semestre) apasionada por el desarrollo de software. Este repositorio contiene el código fuente de mi portafolio personal, donde exhibo mis proyectos más destacados de GitHub.

## 💻 Sobre Mí
Me especializo en crear:
- **Páginas web rápidas y modernas** (enfocadas en rendimiento y buenas prácticas).
- **Aplicaciones móviles multiplataforma** utilizando Flutter.

## 🛠️ Tecnologías del Portafolio
Este sitio web ha sido diseñado con un estilo moderno "ingeniería azul metálico" y construido utilizando tecnologías de alto rendimiento:
- **[Astro](https://astro.build/)**: Framework web optimizado para la velocidad.
- **[Tailwind CSS (v4)](https://tailwindcss.com/)**: Framework de utilidades para un diseño responsivo y moderno (Mobile First).
- **JavaScript Vanilla**: Para la interactividad dinámica y la obtención de datos desde la API de GitHub en tiempo de construcción.

## 🚀 Características Clave
- **Integración con GitHub**: Obtiene y muestra automáticamente mis últimos proyectos, filtrando repositorios específicos de manera inteligente.
- **Cálculo de Semestre Dinámico**: Actualiza automáticamente el semestre en el que me encuentro basado en la fecha de inicio de la carrera.
- **Optimización SEO**: Configurado con meta etiquetas para asegurar la mejor visibilidad en motores de búsqueda (como Google).
- **Despliegue Automático**: Configurado para desplegarse automáticamente en Vercel con cada actualización de código.
